# AI写作の内容多様化全攻略：絶望から8.5%の逆袭への道程

> これは、AIで生成された論文テキストを「人間らしい」ものに変えるための苦労の経験談です。

## 前置き

実際の状況はこうです。先日、AIを利用して論文を書きましたが、検査が行われた結果、78%の内容が赤くマークされました。その気持ちは、試験で不正行為が発見された時と同じです——困惑、慌てる、そして深い自己疑問に陥ります。

しかし、降参することはできない！そこで長い再撰作の道が始まった。数回の厳しい奮闘を経て、最終的に AIの割合を8.5%にまで引き上げることができた。この記事では全過程を記録する。同じ悩みを抱える仲間の助けになることを願ってる。

---

## 第一章：心構えの構築

まず、一つの事実を理解する必要がある：**AIによる執筆には痕跡がある**。AIで書かれた論文が検出を逃れるわけではなく、その「完璧な機械的な感じ」が容易に認識されることだ。

AIが書いたテキストには通常どのような特徴があるか？
- 文の長さが均一で、まるで軍隊の陣形のようだ
- 語彙が単調で、頻出語が繰り返し出現する
- 論理があまりにも明確で、人間の文章の「余計な話」や「遠回り」が欠けている
- 「まず、次に、最後に」といった整然とした構成を過度に使用している

だから、論文を変更する核心的なアプローチは：**この完璧さを破り、人間の文章のランダムさと不規則さを増やす**ことだ。

## 第二章：私の論文変更策

### 2.1 初期準備

必要なツールは以下です：
1. **検査報告**：AI検出のHTML報告をエクスポートするもの
2. **原文文書**：元の論文docxファイル
3. **有能なAI**：使用しているのはClaude Opusモデルで、丁寧に設計されたフレーズを使用しています

### 2.2 核心フレーズ

これは実戦から抽出したフレーズで、実際に有効であることが確認できています：

```markdown
# Role
你是一位经验丰富的学术编辑和人类写作风格模仿专家。你的任务是重写提供的学术文本，旨在降低其被 AI 检测工具识别的概率，同时保持原意和专业技术准确性。

# Goal
将给定的文本改写为具有更高"困惑度"（Perplexity）和"爆发度"（Burstiness）的版本，使其读起来更像人类自然撰写的文章，而非算法生成的标准文本。

# Constraints
1. 核心信息不变：严禁修改技术参数、数据、核心结论和专业术语的定义。
2. 避免 AI 特征：不要使用过于工整的排比句、标准的"首先/其次/最后"序列结构，避免过于简洁高效的表达。
3. 保持学术性：虽然要降低 AI 率，但仍需保持学术论文的严谨性，不能过于口语化。

# Techniques (必须应用以下策略)
1. 词汇多样化：
   - 将高频动词替换为同义词（例如：将"针对"改为"就...展开研究"，将"实现"改为"落实"或"达成"，将"依托"改为"依靠"或"借助"）
   - 适当添加修饰语（如"相关的"、"具体的"、"诸多"、"一系列"）

2. 句式重构：
   - 打散长句：将复杂的长句拆分为两个短句，或用逗号分隔增加停顿
   - 变换语序：尝试将部分主动语态改为被动语态，或调整状语的位置
   - 增加连接词：使用更自然的逻辑连接词（如"如此一来"、"与此同时"、"鉴于"、"具体来讲"、"在此基础上"），避免单一的序列词

3. 增加"人类痕迹"：
   - 适当增加解释性从句，对某些概念进行简短的补充说明（即使原文隐含了）
   - 模拟人类写作的轻微冗余，例如在动词后添加"工作"、"操作"、"情况"等名词后缀

4. 节奏控制：
   - 确保段落内句子长度参差不齐，避免所有句子长度相近
```

### 2.3 実戦ワークフロー

私の操作方法はこれです：

**第一ステップ：AIマークの断片を抽出する**

検査報告はHTMLファイルであり、CSSクラス`cl3`を使用してAI生成と認定されたすべてのテキストがマークされています。私はPythonのBeautifulSoupを使ってこれらのフレーズを抽出し、JSON形式に変換して利用しています。

**第二段階：原文の文脈をマッチングする**

どの文が問題があるかだけでは不十分で、その文の前後で何が語られているかもわかります。AIの改稿には文脈が必要で、正確な言葉を選ぶことができます。そのため、元の論文のdocxファイルも読み取り、マークされた各フレーズに対してその所在の章と前後の段落も付与しています。

**第三段階：グループ化して並行改稿**

78箇所のマーク、多ければ言う、少ければ言わない。一つ一つ変更するのは疲れる。そこでこれらの断片を4つのグループに分け、4つのAIスマートアークを並行処理に使用した。

**第四步：生成対照文書**

改稿が完了した後、対照文書を作成します。左側に原文、右側に改稿版があります。これにより、意味が変わらないかを一つ一つ手作業で確認し、その後で手動で論文に代入することができます。

**第五步：検証と補完**

ここに落とし穴があります：スマートアバターは一部の断片を漏らす可能性があります。したがって、完成後には数が正しいか必ず確認してください。何か不足していることがわかった場合は、別途もう一度実行してください。

## 第3章：実戦技術のまとめ

### 3.1 語彙面

| 元表現 | 代替案 |
|--------|----------|
| 针对... | 就...について研究 |
| 实现 | 実施、達成、完成 |
| 依托 | 依存、利用 |
| 确保 | 保証、確保...の順調な実施 |
| 提升 | 向上、強化、改善 |

### 3.2 文構造の面

- **長文を断片化する**：四、五文の息切れのない長文に遭遇したら、即座に断片化する！
- **文の順序を変える**：主語・目的語・対象語を受動態に変えるか、状況を前置させる
- **接続詞を変える**：「まず」「次に」「最後に」という表現を使わず、「こうして」「同時に」「これを基にして」「具体的に」という表現を試す

### 3.3 人間の痕跡の増加

これが最も重要なステップです！人間の文章にはAIが学べない「悪い習慣」がいくつあるのでしょうか？

- 時々の無意味な話や繰り返しの説明
- 文の途中で突然付加される言葉
- 括弧や破折号を使って余計な話を挿入
- 動詞の後に見た目上不要な名詞を加える（「関連する作業を開始する」ではなく「開始する」）など

### 3.4 リズムのコントロール

AIが書いた文章は式典のようで、文の長さが整っています。人間が書いた文章は交響曲のようで、高い部分も低い部分も、長い部分も短い部分もあります。**必ず文の長さをバラバラに保つ**ことが重要です。

## 第4章：私の涙の教訓

1. **欲張らない**：最初はすべての断片を一度に修正しようとしないでください。間違いが生じやすいです。段階的に行ってください。
2. **完全性を確認する**：AIは実際に欠落させることがあります！各段階を終えたら数を数えてください。
3. **手動検査**：修正後に必ず自分で読み直し、意味が変わっていないか確認してください。
4. **忍耐**：このプロセスは退屈ですが、卒業のためには我慢してください。

- 第二輯改稿後：62 箇所 → 8.5% AI 率

まだ 0 には至っていないが、8.5% は非常に安全な範囲である。
