# AIリライト完全攻略：絶望から8.5%への逆転劇

> これはAIで生成された論文テキストを「人間らしい」形に変換するための痛切な経験談です。

## 前置き

事情はこうです。先日、AIを利用して論文を作成したところ、検査ツールを実行した結果、78%の内容が赤色に表示されました。その気持ちは、試験で不正行為が発覚した時と同じで、困惑、慌て立ち、そして深い自己疑問に陥りました。

しかし、降参することはできない！そこで長い再解釈の道のりが始まった。数回の厳しい奮闘を経て、最終的に AIの割合を8.5％にまで引き上げることができた。この記事では全過程を記録する。同じ悩みを抱える仲間の助けになることを願ってる。

---

## 第一章：心構えの構築

まず、一つの事実を理解する必要がある：**AIによる執筆には痕跡がある**。AIで書いた論文が検出に合格しないわけではないが、その「完璧な機械的な感じ」は容易に認識される。

AIが書いたテキストには通常どのような特徴があるか？
- 文の長さが均一で、まるで軍隊の陣形のように整っている
- 語彙が単調で、頻出語が繰り返し出現する
- 論理があまりにも明確で、人間の文章に見られる「余計な話」や「遠回り」が欠けている
- 「まず、次に、最後に」といった整然とした構成が過度に使われている

だから、論文を変更する核心的なアプローチは：**この完璧さを破り、人間の文章のランダムさや不規則さを増やす**ことである。

## 第二章：私の論文変更手法

### 2.1 前期准备

必要なツールは以下です：
1. **検出レポート**：AI検出のHTMLレポートをエクスポートするもの
2. **原文文書**：元の論文のdocxファイル
3. **強力なAI**：Claude Opusモデルを使用し、丁寧に設計されたフレーズを活用しています

### 2.2 核心フレーズ

これは実戦から抽出したフレーズで、実際に効果があることが確認できています：

```markdown
# 役割
あなたは経験豊富な学術編集者であり、人間のライティングスタイルを模倣する専門家です。あなたの任務は、提供された学術文を書き直し、AI検出ツールでの認識率を低減しつつ、原文の意図と専門的な正確性を保つことです。

# 目標
指定されたテキストを、より高い「困惑度」（Perplexity）と「爆発性」（Burstiness）を持つバージョンに書き直し、アルゴリズムで生成された標準的なテキストよりも、人間が自然に書いた記事のように読まれるようにします。

# 制約
1. 核心情報は変わらない：技術パラメータ、データ、核心結論、専門用語の定義を変更することは禁止されます。
2. AIの特徴を避ける：過度に整った対比表現や標準的な「まず…次に…最後に」の順序構造、過度に簡潔で効率的な表現は使用しないこと。
3. 学術性を保つ：AIの割合を下げるが、学術論文としての厳密性は維持し、過度に口語的にならないこと。

# 手法（以下の戦略を必ず適用）
1. 語彙の多様化：
   - 頻度の高い動詞を同義語に変更（例：「针对」を「就…展开研究」に変え、「实现」を「落实」または「达成」に変え、「依托」を「依靠」または「借助」に変える）
   - 適切な修飾語を追加（「相关的」、「具体的」、「诸多」、「一系列」など）
2. 文構造の再構築：
   - 長い文を分割：複雑な長文を2つの短い文に分割するか、コンマで区切って間隔を作る
   - 語順の変更：一部の能動態文を受動態文に変えたり、状況語の位置を変えたりする
   - 接続詞の追加：より自然な論理接続詞（「如此一来」、「与此同时」、「鉴于」、「具体来讲」、「在此基础上」など）を使用し、単一の順序語を避ける
3. 「人間の痕跡」の追加：
   - 適切な説明的文を追加し、原文が含む場合の概念について簡潔な補足をする
   - 人間のライティングのわずかな冗長さを模倣する（例：動詞の後に「工作」、「操作」、「情况」などの名詞語尾を加える）
4. リズムの制御：
   - 段落内の文の長さが不均等になるようにし、全ての文が同じ長さになるのを避ける
```

### 2.3 実戦ワークフロー

私の操作方法はこれです：

**第一步：AIマークの断片を抽出する**

検査報告はHTMLファイルであり、CSSクラス`cl3`を使用してAI生成と認定されたすべてのテキストをマークしています。私はPythonのBeautifulSoupを使ってこれらのフレーズを抽出し、JSON形式に変換して利用しています。

**第二ステップ：原文の文脈をマッチングする**

どの文が問題があるかだけでは不十分です。この文の前後に何が語られているかも知る必要があります。AIの改変時には文脈が必要で、正確な言葉を選ぶことができます。そのため、元の論文のdocxファイルも読み取り、マークされた各フレーズに対してその所在する章と前後の段落も記録します。

**第三ステップ：グループ化して並行改変**

78箇所のマーク、多ければ言う、少ければ言わない。一つ一つ変更するのは疲れる。そこでこれらの断片を4グループに分け、4つのAIスマートアイドルで並行処理した。

**第四ステップ：対照文書の作成**

改稿が完了した後、対照文書を作成します。左側に原文、右側に改稿版があります。これにより、意味が変わらないかを一つ一つ手作業で確認し、その後で手動で論文に代入することができます。

**第五步：检查不足并进行补充**

ここに注意点があります：スマートアバターが一部の断片を漏らす可能性があります。ですので、完成後必ず数を確認し、正しいかどうかをチェックしてください。何か不足していることがわかった場合は、別途もう一度実行してください。

## 第三章：実戦技術のまとめ

### 3.1 語彙面

| 原表达 | 替换方案 |
|--------|----------|
| 针对... | 就...展开研究 |
| 实现 | 落实、达成、完成 |
| 依托 | 依靠、借助 |
| 确保 | 保证、确保...的顺利实现 |
| 提升 | 提高、增强、改善 |

### 3.2 句式层面

- **打散长句**：遇到那种四五行不带喘气的长句，果断拆！
- **调整语序**：主谓宾改成被动，或者把状语搬到前面
- **替换连接词**：别总用"首先/其次/最后"，试试"如此一来"、"与此同时"、"在此基础上"、"具体来讲"

### 3.3 增加人类痕迹

これが最も重要なステップです！人間の文章にはAIでは学べない「悪い習慣」がいくつあるのでしょうか？

- たまに無意味な話や繰り返しの説明
- 文の途中で突然別の文を追加する
- 括弧や破折符を使って余計な話を挟む
- 動詞の後に必要ない名詞を加える（「関連する作業を開始する」ではなく「開始する」）

### 3.4 リズムの管理

AIが書いた文章は式典のようで、文の長さが整っています。人間が書いた文章は交響曲のようで、高い部分も低い部分も、長い部分も短い部分もあります。**必ず文の長さをバラバラに保つ**ことです。

# マークダムポスト: マークダム構文をそのまま保持（見出し、リスト、太字/斜体、表、引用文）



## 第四章：我的血泪教训

1. **不要贪多**：最初はすべての断片を一度に修正しようとしないこと。間違いが生じやすいので、段階的に行うこと
2. **検査完整性**：AIは本当に書き落しがち！各段階を終えたら数を数えること
3. **人工検査**：修正後は必ず自分で読み直すこと。意味が変わっていないか確認すること
4. **忍耐**：このプロセスは退屈だが、卒業のために我慢する
