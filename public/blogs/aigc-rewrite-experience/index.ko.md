# AI 리라이팅 완전 정복: 절망에서 8.5%의 역전으로

> 이는 AI로 생성된 논문 텍스트를 "인간처럼" 변환하는 방법에 관한 뼈저린 경험담입니다.

## 서문

사실은 이렇습니다. 최근에 AI를 이용해 논문을 작성했는데, 검사 도구를 실행하자 78%의 내용이 빨간색으로 표시되었습니다. 그 기분은 시험 부정행위가 발각된 것과 같았습니다—어색함, 당황함, 그리고 깊은 자기 의심에 빠졌습니다.

하지만 우리는 패배를 인정할 수 없어요! 그래서 긴 과정의 내용 복제 방지 작업을 시작했습니다. 여러 차례 힘든 싸움 끝에 결국 AI의 비율을 8.5%까지 올렸습니다. 이 글은 전체 과정을 기록하는 것이며, 같은 문제를 겪는 동료들에게 도움이 되길 바랍니다.



## 제1장: 심리 구축

먼저, 한 가지 사실을 이해해야 합니다: **AI로 작성한 글에는 흔적이 남습니다**. AI로 글을 쓴 논문이 검사에 통과하지 못할 것이라는 의미가 아니라, 그 "완벽한 기계적 느낌"이 쉽게 식별될 수 있다는 것입니다.

AI가 작성한 텍스트의 일반적인 특징은 무엇인가요?
- 문장 길이가 균일하여 군대 행진처럼 보임
- 어휘가 단조로워 자주 사용되는 단어가 반복됨
- 논리가 너무 명확하여 인간의 글에 있는 "불필요한 말"과 "회피적인 표현"이 부족함
- "먼저, 그 다음에, 마지막으로"와 같은 정돈된 구조를 과도하게 사용함

그러므로 참조를 줄이는 핵심 방안은 **이러한 완벽함을 깨고 인간의 글에 있는 무작위성과 불규칙성을 더하는 것**입니다.

## 제2장: 제 참조 줄이기 방안

### 2.1 전제 준비

다음 도구들을 준비해야 합니다:
1. **검사 보고서**: AI 검사 결과를 포함한 HTML 보고서를 내보내기
2. **원문 문서**: 원본 논문의 docx 파일
3. **효율적인 AI**: Claude Opus 모델을 사용하며, 잘 설계된 프롬프트를 활용함

### 2.2 핵심 프롬프트

이것은 실제 작업에서 추출한 프롬프트로, 실제로 효과가 입증되었습니다:

```markdown
# 역할
당신은 경험이 풍부한 학술 편집가이자 인간의 글쓰기 스타일을 모방하는 전문가입니다. 당신의 임무는 제공된 학술 텍스트를 다시 작성하여 AI 검출 도구에 의해 식별되는 확률을 낮추면서 원래의 의미와 전문적인 기술적 정확성을 유지하는 것입니다.

# 목표
주어진 텍스트를 더 높은 "Perplexity"와 "Burstiness"를 가진 버전으로 재작성하여, 알고리즘으로 생성된 표준 텍스트보다 인간이 자연스럽게 쓴 글처럼 읽히도록 합니다.

# 제한 사항
1. 핵심 정보는 변하지 않음: 기술적 매개변수, 데이터, 핵심 결론 및 전문 용어의 정의를 변경하지 말 것
2. AI 특징 피하기: 너무 정형적인 배열 문장이나 표준적인 "먼저/다음/마지막" 구조를 사용하지 말 것, 너무 간결하고 효율적인 표현을 피할 것
3. 학술적 성격 유지: AI 비율을 낮추되 학술 논문의 엄밀성을 유지해야 하며 너무 구어체적이 되지 않을 것

# 기법 (반드시 적용해야 함)
1. 어휘 다양화:
   - 고빈도 동사에 동의어를 사용 (예: "대상으로"를 "바로...에 대해 연구를 진행"으로 변경, "실현"을 "실행" 또는 "달성"으로 변경, "기반으로"를 "기반을 두고" 또는 "도움을 받아"로 변경)
   - 적절한 수식어 추가 (예: "관련된", "구체적인", "많은", "일련의" 등)

2. 문장 구조 재구성:
   - 긴 문장 분리: 복잡한 긴 문장을 두 개의 짧은 문장으로 나누거나 쉼표로 구분하여 휴식감을 주기
   - 문장 순서 변경: 일부 능동태를 수동태로 변경하거나 전치사의 위치를 조정하기
   - 연결어 추가: 더 자연스러운 논리적 연결어 사용 (예: "이렇게 되면", "동시에", "고려할 때", "구체적으로는", "이 기반 위에서")으로 단순한 순서어를 피하기

3. "인간의 흔적" 추가:
   - 적절한 설명 부정문 사용: 원문에 이미 포함된 일부 개념에 대한 간단한 설명 추가
   - 인간 글쓰기의 약간의 중복 사용: 동사 뒤에 "작업", "조작", "상황" 등의 명사 접미사를 추가하여 표현하기

4. 리득 조절:
   - 문단 내 문장의 길이가 불규칙하도록 하여 모든 문장의 길이가 같지 않도록 주의
```

### 2.3 실전 작업 과정

저는 이렇게 진행합니다:

**1단계: AI 표시 부분 추출**

검사 보고서는 HTML 파일로, AI로 생성된 것으로 판단된 모든 텍스트가 CSS 클래스 `cl3`로 표시되어 있습니다. 저는 Python의 BeautifulSoup을 사용하여 이러한 부분들을 추출하고 JSON으로 변환하여 보관합니다.

**두 번째 단계: 원문의 맥락과 일치시키기**

문제가 있는 문장이 무엇인지만 알고 있다고 충분하지 않아요. 이 문장이 앞뒤에 무엇을 의미하는지도 알아야 합니다. AI가 재작성할 때는 맥락이 필요하여 정확한 단어를 사용할 수 있어요. 그래서 원문 docx 파일도 함께 읽고, 표시된 각 부분에 해당되는 장과 앞뒤 단락도 함께 제공합니다.

**세 번째 단계: 그룹별 병렬 수정**

78개의 표시가 있어서 많다고 하거나 적다고 하지 않겠습니다. 하나하나 수정하는 것은 너무 힘들어요. 그래서 이 부분들을 4개의 그룹으로 나누고 4개의 AI 지능형 캐릭터로 병행 처리했습니다.

**4단계: 대조 문서 생성**

수정이 완료된 후 대조 문서를 생성합니다. 왼쪽은 원문이고, 오른쪽은 수정된 버전입니다. 이를 통해 하나하나 수동으로 확인하여 의미가 변하지 않았는지 확인한 후, 손으로 논문에 교체할 수 있습니다.

**5단계: 결함 점검**

여기에 한 가지 주의점이 있습니다: 스마트 아바타가 일부 부분을 누락할 수 있습니다. 따라서 완료 후 반드시 수량이 맞는지 확인해야 합니다. 무언가 누락된 것을 발견하면 별도로 한 번 더 실행해야 합니다.

## 3장: 실전 기법 요약

### 3.1 어휘 측면

| 원 표현 | 대체 방안 |
|----------|----------|
| ...에 대해 | ...에 대해 연구 |
| 실현 | 이행, 달성, 완료 |
| 의존 | 의존, 이용 |
| 보장 | 보장, ...의 원활한 실현을 보장 |
| 향상 | 향상, 강화, 개선 |

### 3.2 문장 구조 측면

- **긴 문장을 분리하기**: 호흡이 없는 4~5행의 긴 문장을 만나면 즉시 분리하세요!
- **문장 순서 조정**: 주어-동사-목적어를 수동태로 바꾸거나 부사어를 앞쪽으로 옮기기
- **연결어 교체**: "먼저/다음으로/마지막으로" 같은 표현을 계속 사용하지 말고 "이렇게 되면", "동시에", "이 기반 위에서", "구체적으로 말하자면" 등을 시도해보기

### 3.3 인간적 흔적 추가

이것이 가장 중요한 단계입니다! 인간의 글쓰기에서 AI가 배우지 못하는 "나쁜 습관"은 무엇인가요?

- 가끔 나오는 쓸데없는 말과 반복적인 설명
- 문장 중간에 갑자기 추가되는 말
- 괄호나 하이픈을 사용해 부수적인 내용을 넣는 것
- 동사 뒤에 불필요해 보이는 명사가 추가된 것 ("관련 작업을 진행하다"가 "진행하다"보다 더 많음)

### 3.4 리듬 조절

AI가 쓴 글은 행진식처럼 문장의 길이가 균일합니다. 인간이 쓴 글은 교향곡처럼 높고 낮음, 길고 짧음이 섞여 있습니다. **반드시 문장의 길이를 불규칙하게 만드세요**.



## 4장: 내 피와 눈의 교훈

1. **너무 많은 것을 원하지 마세요**: 처음에는 모든 부분을 한 번에 수정하려고 하지 마세요. 실수가 쉽게 생기기 때문입니다. 여러 번에 나누어서 진행하세요.
2. **완전성을 확인하세요**: 스마트 아바타는 실제로 누락을 하기도 합니다! 매번 완료한 후 수량을 세어보세요.
3. **인간이 확인하세요**: 수정한 후 반드시 직접 읽어보세요. 의미가 변하지 않았는지 확인하세요.
4. **인내심을 가지세요**: 이 과정은 매우 지루합니다. 하지만 졸업을 위해 참아야 합니다.
